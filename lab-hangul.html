처리 단계 비교 (Apple SD Gothic Neo)

0. 처음 (DEC-032/033 이전)

Albert/헬베티카에 한글이 없어 시스템 대체 서체(맥 = Apple SD Gothic Neo)로 나옴. 크기·간격·줄바꿈 보정 없음.

1. D만

word-break: keep-all, line-break: strict, 대체 서체 순서 명시, 긴 글 줄높이 1.7. 크기·간격은 그대로.

2. A + D (r 1.0, 간격은 원래 고정폭, Medium)

한글 높이를 대문자와 같게 하고 대문자 띠 가운데에 맞춤. 글자 폭은 원래 고정폭(평균 간격 ≈ 3.8단위, 글자마다 다름). 0.82배로 줄면서 획이 가늘어짐(농도 0.303 vs 영문 0.380).

3. A + B + D · r 1.0 · N 4 · Bold

모든 음절 사이 잉크 간격 4단위(= TYPE-024 기본 2 + 2). 원래 평균(≈3.8)과 비슷하지만 고르게. 굵기는 글줄 농도를 영문과 맞춰 Bold(0.375 vs 영문 0.380).

4. A + B + D · r 1.0 · N 6 · Bold

잉크 간격 6단위(0.17 cap). 농도 0.355.

5. A + B + D · r 1.1 · N 4 · SemiBold

한글을 대문자보다 10% 크게(위아래로 0.05 cap씩 띠를 넘음). 커진 만큼 한 단계 가는 SemiBold로 농도 0.373.

6. A + B + D · r 1.1 · N 6 · SemiBold
